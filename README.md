## 核心特性

- **无万向节锁 3D 旋转矩阵陀螺仪控光**：采用完整三维姿态矩阵 $M = R_0^T R_{\text{device}}$ 解算手机相对倾角，彻底消除传统欧拉角在手机竖直握持（$\beta \approx 90^\circ$）时的左右翻转跳变；无论平放、斜握还是竖举环视，左右/俯仰旋转手机都能丝滑连续地驱动圣堂外的太阳方位角与高度角。
- **纯粹以光显化立体建筑**：
  - **隅壁与圣龛浮雕**：切石灰岩墙面上的哥特尖拱壁龛与巴洛克雕花画框具备真实三维深度与法线起伏；当斜射彩光扫过时，浮雕画框实时在石墙上投下随陀螺仪旋转拉长的掠射阴影。
  - **四叶束柱与体积暗影隧道**：伫立于黑暗中的哥特束柱不仅在受光侧浮现高光石棱，更会在发光的丁达尔雾气中切出清晰的圆柱形三维暗影走廊。
  - **尖拱交叉肋架穹顶与圣坛石阶**：低仰角日光向上掠亮高处的交叉石拱肋，高仰角日光则垂落照亮圣坛双层石阶与石板地的菲涅尔微反光。
- **古法吹制彩窗折射焦散与微色散**：程序化绘制 `512×1024` 沙特尔/圣礼拜堂风双尖拱五层叙事花窗、心形四叶花饰与十二瓣玫瑰窗，叠加吹制玻璃厚度梯度与拉普拉斯焦散聚光场，在石墙上投出温润灵动的水波状珠光焦散与细微棱镜色散。
- **双瓣米氏（Mie）丁达尔散射与 2200 颗景深微尘**：实时光线步进穿过翻涌的熏香微雾，2200 颗悬浮尘埃仅在飘入彩色光柱时点亮散景星芒，离开光束即归于无形。
- **三处观察机位 + 琉璃泛音声景**：一键切换「隅壁 / 柱廊 / 穹顶」三重视角（陀螺仪模式下单指滑动可自由环视）；内置 Web Audio 实时合成的圣堂琉璃泛音与石拱混响，音色明暗随日光仰角实时流转；双击屏幕可隐去界面进入纯黑观光模式。
